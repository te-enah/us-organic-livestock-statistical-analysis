# Evaluation of U.S. Certified Organic Livestock Growth (2008–2011)
### 📊 Agricultural Policy & Statistical Analysis Case Study

## Project Overview
This repository contains a comprehensive statistical evaluation of the United States Certified Organic Livestock (COL) sector between 2008 and 2011. Working from the perspective of an Agricultural Policy Analyst, the objective was to determine whether observed shifts in certified organic livestock populations reflect true systemic industry growth or merely random, localized fluctuations.

Due to extreme skewness and massive operational disparities between production states, this project showcases the deliberate selection and application of both **parametric** and **non-parametric** statistical frameworks to deliver robust, objective insights for policymakers.

---

## Key Technical Skills Demonstrated
* **Exploratory Data Analysis (EDA):** Data profiling, metric segmentation, and variance mapping.
* **Hypothesis Testing Frameworks:** Paired and independent group experimental formulations.
* **Advanced Data Manipulation:** Dynamic dataset filtering via array matching and structural isolating formulas.
* **Advanced Statistics:** Mitigating violations of normality assumptions, evaluating Type I/II error inflation risks, and calculating statistical power limitations.
* **Data Visualization:** Distribution profiling using adjusted bucket histograms.
